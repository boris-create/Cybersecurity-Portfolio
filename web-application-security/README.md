
# Web Application Security

Projects focused on identifying and understanding vulnerabilities in web applications, using intentionally vulnerable apps and personal builds — never unauthorized targets.

## What's Here

- Testing against apps like DVWA, Juice Shop, or similar sanctioned targets
- OWASP Top 10 vulnerability walkthroughs (XSS, SQLi, CSRF, etc.)
- Burp Suite testing methodology and findings
- Basic secure coding / remediation notes
