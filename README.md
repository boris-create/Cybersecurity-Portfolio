## About Me

Recent graduate with a background in cybersecurity, building practical, real-world experience through independent projects. This repo is where that work lives — labs I've built myself, tools I've written, and write-ups from things I've broken, defended, or automated. I'm broadly interested across cybersecurity and still narrowing toward a specialization, so the projects here intentionally span multiple domains.

## How This Repo Is Organized

Each folder below is a self-contained domain. Individual projects live in their own numbered subfolder with their own README, so a reviewer can open exactly one project without wading through the rest.

## Sections

| Section | What's In It |
|---|---|
| [Network Security](./network-security) | Home-lab network builds, segmentation, firewall/IDS configs, packet analysis |
| [Web Application Security](./web-application-security) | Vulnerability testing against intentionally vulnerable apps, findings write-ups |
| [Scripting & Automation](./scripting-automation) | Python/Bash tools built to automate recon, log parsing, or repetitive tasks |
| [Digital Forensics & Incident Response](./digital-forensics-incident-response) | Simulated incident investigations, memory/disk forensics exercises |
| [CTF Write-ups](./ctf-writeups) | Solved challenges with methodology, not just flags |
| [Cloud Security](./cloud-security) | AWS/Azure misconfig hunts, IAM hardening, cloud lab builds |
